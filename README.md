# The Power of Color and Emotion in Art

A responsive HTML, CSS, and JavaScript portfolio starter built around the six required sections in the uploaded Art Appreciation final project instructions.

## Files
- `index.html` — all six portfolio sections and references
- `style.css` — responsive minimalist styling
- `script.js` — mobile navigation interaction

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For a more reliable local preview, open the folder in Visual Studio Code and use the Live Server extension.

## Personalize before submitting
- Replace `[Your Complete Name]`, `[Year & Section]`, and `[Instructor’s Name]`.
- Create and photograph/scan your own original artwork for Part 4. Replace the decorative placeholder with your own image.
- Revise the artist statement and final reflection so they describe your actual experience and process.
- Confirm all artwork titles, dates, and source details with class materials.
- Verify each image URL and image-use rights; some external image URLs may change. Replace broken images with verified museum or Wikimedia Commons file URLs.
- Add any class readings or instructor-provided sources to References & Image Credits.
- Publish the site using a static host such as GitHub Pages, Netlify, or Vercel, and submit the published URL if required by your instructor.

The content is a draft starter; check your instructor's expectations and make the written analysis your own.
